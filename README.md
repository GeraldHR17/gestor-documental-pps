# Sistema Integral de Gestión Documental y Portal Web de Gobierno Abierto y Transparencia Municipal

Proyecto desarrollado como parte de la Práctica Profesional Supervisada (PPS) de la Universidad Nacional de Costa Rica.

## Descripción

Sistema orientado a la gestión, organización, consulta y publicación de documentación institucional de la Municipalidad de Palmares, considerando los requerimientos relacionados con transparencia y gobierno abierto.

## Tecnologías principales

- Node.js
- NestJS
- TypeScript
- Vue.js 3
- Vite
- MySQL
- Docker
- Docker Compose
- Git
- GitHub

## Estructura del proyecto

```text
backend/       API REST desarrollada con NestJS
frontend/      Aplicación web desarrollada con Vue.js
base-datos/    Scripts y recursos relacionados con MySQL
documentacion/ Documentación técnica del proyecto
docker/        Configuración auxiliar de Docker
